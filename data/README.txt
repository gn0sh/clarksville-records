These files carry the facts the pages show, each with the source document it came from. This notice applies to every file in this folder, including a file copied away from it.

fetched_at is the day in Coordinated Universal Time (UTC) a file was first fetched, so it can be one day after the fetch date the pages show (the day in Clarksville).

## The analysis report (Tyler Munis `bgnyrpts`), same in FY2024, FY2026, FY2027
- Title line exactly `NEXT YEAR / CURRENT YEAR BUDGET ANALYSIS`; above it `CITY OF CLARKSVILLE`; under it
  `PROJECTION: <yr> <yr> City of Clarksville Budget FOR PERIOD 99` and `ACCOUNTS FOR:`.
- Header: two lines. Line 1 the years only (`2024 2025 2025 2025 2025 2026`); line 2 the **fund name at the left**
  (`General Fund`, `Drug Enforcement`, ...) then `ACTUAL | ORIG BUD | REVISED BUD | ACTUAL | PROJECTION | <budget year>
  | COMMENT`. Budget-year column: `2nd Readin` (FY2024, FY2026: amount at the ordinance's second reading = adopted),
  `Mayor` (FY2027 as presented 5/29/2026 = the Mayor's proposal). `Readin` ends 4.8 pt before `COMMENT` (closer than the
  8 pt phrase gap), so COMMENT must start its own band.
- Font Lucida Console (monospace, 4.82 pt per character). Amounts print cents, revenues are negative (credits):
  `-1,404.28`, `.00`, `12,331,758.00`. Every row ends with a `________` comment blank.
- Rows: `<org> <object> [<project>] <short name> <6 amounts> ________`. Org 6-8 digits (`100310` revenue,
  `10411001` expense), object 5 digits for revenue (`31111`), 4 for expense (`4113`), optional project code (`FL10`,
  `421`, `25103`). Section heading `<org> <name>` (no amounts). Section total `TOTAL <name, cut to 22 chars>`.
  Fund total `TOTAL <fund name, cut to 22>` right after the fund's last section total, net of revenue (negative) and
  expense. End of each report run: `TOTAL REVENUE`, `TOTAL EXPENSE`, `GRAND TOTAL` over every fund of that run, then
  `** END OF REPORT - Generated by <staff name> **` (never stored).
- Report runs: FY2024 and FY2026 one run for the general and special funds plus one run for Vehicle Replacement;
  FY2027 one run per department (69 runs), so a fund's total there covers that run only.
- Page foot: `Report generated: <date time> Page N`, `User: <login>`, `Program ID: bgnyrpts` (never stored).
- Wide amounts touch: at 100 M and up the columns print with no space (`TOTAL REVENUE-183,187,308.58-197,098,013.00`),
  so pdftotext returns one word. They are split back only where every piece is a whole amount and the monospace
  character width puts each piece's right edge on its column edge; otherwise the row is held (column-align).
- Fund numbers: the books print none on these pages (the summary page's `FUND #` 1100, 1300 ... does not match the org
  codes), so `fund_no` is null and the fund is its printed name.

## Config and code consequences (step 2)
`config/localities/clarksville-tn/finance.yml` sets, as optional keys the county file does not use (so county output
cannot change): `amount_unit: cents`, `header_year_lines`, `fund_from_header`, `header_split_before: [COMMENT]`,
`ignore_tokens` (the `________` rule), `split_glued_amounts`, `rows.org_code`, `rows.statement_by_code` (3xxxx revenue,
4xxx expense), `rows.fund_total_by_name`, `rows.run_totals` + `rows.run_end`, `books_not_read` (FY2025). Read pages:
FY2024 50-156, FY2026 33-138, FY2027 9-434 (the title line picks the analysis pages; detail-report pages between them
are skipped). Column kinds: ACTUAL actual, ORIG BUD adopted, REVISED BUD amended, PROJECTION projected, 2nd Readin
adopted, Mayor proposed (a new kind: the FY2027 file is the Mayor's proposal, not an adopted budget).
